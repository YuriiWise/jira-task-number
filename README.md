# Copy Jira Task Number

Chrome-розширення, що додає кнопку **Copy** поруч із номером задачі (напр. `PROJ-123`) на сторінці задачі Jira та в модальному вікні задачі (борд, беклог, пошук). Підтримує Jira Cloud і Jira Server/Data Center.

## Встановлення
1. Відкрийте `chrome://extensions`, увімкніть **Developer mode**.
2. **Load unpacked** → оберіть цю папку.
3. Відкрийте **Details → Extension options**, впишіть URL Jira (напр. `https://company.atlassian.net`), натисніть **Зберегти** і дозвольте доступ.
4. Перезавантажте вкладки Jira.

Розширення працює тільки на вказаних у налаштуваннях адресах.
